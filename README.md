# ミャンマー語 単語分解ツール

ミャンマー語(ビルマ語)の単語を入力すると、文字の組み立て(子音・介子音・母音・声調記号など)に分けて表示するツールです。

**▶ ツールを使う:** https://gengootakulab-star.github.io/myanmar-words/

「言語オタクの多言語学習ラボ」で公開しているツールの一つです。
サイト: https://gengootakulab-star.github.io/

## できること

- 単語を入力すると、文字のパーツごとのブロックに分けて表示します
- ブロックをタップすると、そのパーツの説明が出ます(子音なら発音のコツ、介子音なら役割など)
- 発音記号(IPA)を音節ごとに表示します(規則から作った目安です)
- 辞書にある単語は意味を表示します。よく使う約250語は日本語、それ以外は英語です

## 使い方

1. 入力欄にミャンマー語の単語を入れます(コピー&ペーストでも大丈夫です)
2. 分解されたブロックが表示されます
3. 気になるブロックをタップして、説明を読みます

## データについて

- 単語データは [Wiktionary](https://en.wiktionary.org/) をもとにしています。データは [kaikki.org](https://kaikki.org/) で公開されているものを使いました
- Wiktionary の内容は [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ja) で公開されています。このツールに入っている単語データも、同じ CC BY-SA 4.0 の条件で使えます
- 日本語の意味は、運営者がAIの助けを借りて付けたものです

## ご注意

- 個人が趣味で作っている学習用のツールです。分解の結果・読み・意味に誤りが含まれている可能性があります。読みは実際の発音と違うことがあります
- 正確さが必要なときは、辞書や先生など、ほかの情報源もあわせて確認してください
